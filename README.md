## LLMs & Foundation Models
Large language models, foundation architectures, and inference engines.

- [OpenClaw](https://ossaihub.com/tool/openclaw) — 2026 breakout personal AI assistant framework (modular, local-first, privacy-focused)
- [Ollama](https://ossaihub.com/tool/ollama) — Run powerful LLMs locally with one-line installer and OpenAI-compatible API
- [vLLM](https://ossaihub.com/tool/vllm) — High-throughput, memory-efficient inference engine for LLMs with PagedAttention
- [Llama.cpp](https://ossaihub.com/tool/llama-cpp) — State-of-the-art LLM inference in pure C/C++ — runs on almost anything
- [Hugging Face Transformers](https://ossaihub.com/tool/huggingface-transformers) — The standard library for loading, fine-tuning, and deploying 1M+ models
- [LangChain](https://ossaihub.com/tool/langchain) — Build composable LLM applications (chains, agents, memory, tools)
- [LlamaIndex](https://ossaihub.com/tool/llamaindex) — Data framework for connecting custom data to LLMs (RAG made easy)
- [Qwen](https://ossaihub.com/tool/qwen) — Alibaba's powerful open-weight LLM family (strong multilingual performance)
- [DeepSeek-V3](https://ossaihub.com/tool/deepseek-v3) — Massive 671B MoE model with exceptional reasoning and coding

## Agent Frameworks
Frameworks for building autonomous AI agents and workflows.

- [Auto-GPT](https://ossaihub.com/tool/auto-gpt) — The original autonomous agent — think-plan-act-observe-critique loop
- [Langflow](https://ossaihub.com/tool/langflow) — Low-code visual platform for building LLM agents and workflows
- [CrewAI](https://ossaihub.com/tool/crewai) — Multi-agent orchestration framework — role-based collaboration
- [BabyAGI](https://ossaihub.com/tool/babyagi) — Task-driven autonomous agent inspired by task management
- [Dify](https://ossaihub.com/tool/dify) — Open-source LLM app development platform (visual builder + agents)
- [Letta](https://ossaihub.com/tool/letta) — Stateful agents with memory and long-term context
- [OpenInterpreter](https://ossaihub.com/tool/openinterpreter) — Let LLMs run code on your computer (local agents)

## Computer Vision
Image recognition, object detection, segmentation, and visual AI tools.

- [YOLOv11](https://ossaihub.com/tool/yolov11) — Latest Ultralytics YOLO — real-time object detection & segmentation
- [Segment Anything Model 2 (SAM 2)](https://ossaihub.com/tool/segment-anything-2) — Meta's universal image & video segmentation model
- [ControlNet](https://ossaihub.com/tool/controlnet) — Add spatial control to Stable Diffusion (poses, edges, depth)
- [Grounding DINO](https://ossaihub.com/tool/grounding-dino) — Open-set object detection with text prompts
- [Depth Anything V2](https://ossaihub.com/tool/depth-anything-v2) — State-of-the-art monocular depth estimation

## Multimodal
Multi-modal AI combining text, image, audio, video, and more.

- [LLaVA](https://ossaihub.com/tool/llava) — Large Language and Vision Assistant — visual instruction following
- [Florence-2](https://ossaihub.com/tool/florence-2) — Microsoft's unified vision-language model for captioning, detection, OCR
- [Kosmos-2](https://ossaihub.com/tool/kosmos-2) — Grounding multimodal LLM — text + bounding boxes
- [Qwen-VL](https://ossaihub.com/tool/qwen-vl) — Alibaba's vision-language model family

- [Dify](https://ossaihub.com/tool/dify) — Open-source platform for building & deploying LLM apps
